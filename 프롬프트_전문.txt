[슬라이드 31]  예제 3-2. 날씨판에 날씨 붙이기
— P-6  날씨 API 붙이기 (AI 코딩 도구)
----------------------------------------------------------------
PRD의 F-04를 만들어 줘. 시작 전에 고칠 파일과 이유를 먼저 보여 주고 승인을 기다려.
Open-Meteo 날씨 API(키 없음)로 세종 · 대전 · 태안 · 보령의 오늘 최고 기온 · 최대 풍속(m/s) · 강수확률을 받아
일정마다 R-01~R-04로 판단해 표에 '날씨' · '판단' 칸으로 보여 줘.
API 주소 만들기와 응답 해석은 logic.js에, 호출은 app.js에. API가 실패해도 목록은 보이게.
주소 끝에 ?test=wind 를 붙이면 풍속을 12로 바꿔 규칙을 시험할 수 있게 해 줘.
