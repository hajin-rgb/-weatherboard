## 날씨 확인 (F-04)
- [Open-Meteo](https://open-meteo.com/en/docs)의 키 없는 API로 한국 시간 기준 오늘 예보를 가져옵니다. 인터넷 연결이 필요합니다.
- 표의 날씨는 최고 기온(℃) · 최대 풍속(m/s) · 최대 강수확률(%) 순서입니다.
- T-03: 페이지를 열어 4개 지역의 날씨와 판단을 확인합니다. 지역별 예보 수치는 같을 수도 있습니다.
- T-04: 주소 끝에 `?test=wind`를 붙여 새로고침합니다. 날씨 수신 후 기본 고소 일정 2건이 `중지 검토 (강풍)`으로 표시되는지 확인합니다.
- API 실패: 인터넷을 끊고 새로고침해도 일정이 보이고, 실패 안내와 `날씨 확인 전`이 표시되는지 확인합니다. 실내는 항상 `영향 없음`입니다.
- 강풍 테스트도 API 수신이 필요하며, 실패한 지역의 날씨를 임의로 만들지 않습니다.
